# 系統備份

把系統的**資料庫、專案附件、例外紀錄的堆疊檔、Token 用量的原始檔與登入金鑰**打包成一個 zip 備份檔。系統每天自動備份一次，也可以在這裡**立即備份**、**下載**或**刪除**舊的備份。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：主機壞掉、資料被誤刪或被破壞時，可以用備份把系統還原到備份當時的樣子；備份之前要靠人手動複製好幾個資料夾，很容易漏。
- **誰會用到**：負責維運的系統管理員。平常確認每天的備份都有成功，定期把備份下載到另一個安全的地方保存。
- **它在系統的哪個位置**：左側選單「系統管理 › 系統設定與維運 › 系統備份」。自動備份的執行時間與結果也看得到在「排程作業」的「系統備份」；保留幾份在「系統參數」調整。
- **開始前要準備**：確認備份目錄所在的磁碟有足夠空間，以及下載後要放在哪個安全的地方（備份含所有資料與登入金鑰）。
- **做完會得到**：備份目錄裡多一個 `backup-日期-時間.zip`；超過保留份數的舊備份在下一次備份成功後自動刪除；下載與刪除都會寫進稽核紀錄。
- **它不做什麼**：不能在畫面上還原（還原必須停站並由部署人員執行還原腳本）；不會備份 AI 對話內容（可在系統參數開啟）、日誌檔與網站程式本身；備份檔沒有加密。

## 一、功能摘要

在這裡可以做什麼：

- 看下一次自動備份的時間、上一次備份的結果，以及保留份數。
- 按「立即備份」馬上建立一份備份（在背景進行，完成後頁面自動更新）。
- 看所有備份的建立時間、大小、系統版本、觸發方式與內容。
- 下載備份檔，複製到另一個安全的地方保存。
- 刪除不需要的備份。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 系統管理員（日常巡檢） | 確認每天的備份都成功、大小合理，備份目錄沒有塞滿。 |
| 系統管理員（異地保存） | 定期下載最新的備份，存到另一台主機、隨身碟或公司的檔案伺服器。 |
| 系統管理員（重大變更前） | 升級系統、大量匯入或修改資料之前，先按「立即備份」留一份。 |

### 備份裡有什麼

| 內容 | 說明 |
|---|---|
| 資料庫 | 所有資料表的完整快照，備份時網站照常運作。 |
| 專案附件 | 專案上傳的所有附件檔案。 |
| 例外堆疊檔、Token 原始檔 | 「系統例外紀錄」與「Token 用量」的詳細內容檔。 |
| 登入金鑰 | 網站加密登入資訊用的金鑰；少了它，還原後所有人都要重新登入。 |
| AI 對話內容 | 預設**不**備份（內容含日誌與錯誤細節、檔案大、本來只保留 90 天）；需要時在「系統參數」開啟。 |

⚠️ 備份含所有資料與登入金鑰，**拿到備份檔的人可以偽造登入身分**。下載後請放在只有負責人能存取的地方，用完的副本請刪除。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 管理員 | 進入這一頁並使用所有功能。只有帳號勾選了「管理員」的人能進來，這個權限**不在**角色管理的權限表裡，無法透過角色開放。 |

### 它跟其他頁面的分工

| 想做的事 | 去哪裡 |
|---|---|
| 立即備份、下載、刪除備份 | 這一頁 |
| 修改自動備份的時間 | 由部署人員修改設定檔（「排程作業」頁看得到時間） |
| 停用自動備份、看每次執行的紀錄 | 「排程作業」的「系統備份」 |
| 修改保留份數、要不要備份 AI 對話內容 | 「系統參數」的「備份」分類 |
| 查誰下載或刪除了備份 | 「稽核紀錄」 |
| 從備份還原 | 由部署人員停站後執行還原腳本（見「備份與還原操作手冊」） |

備份在背景執行，不會出現持續顯示的處理進度視窗；備份進行中，「上次執行」顯示「執行中」，頁面每 5 秒自動更新到結果出來為止。

## 四、建議這樣操作，會得到什麼

### 每週巡檢並異地保存

1. 打開這一頁，確認「上次執行」是「成功」、最新一份的時間是當天凌晨（預設每天 02:00 自動備份）。
2. 按最新一份的「下載」，把檔案存到另一台主機或公司的檔案伺服器（只有負責人能存取的位置）。
3. 舊的異地副本依公司規定保留或刪除。

**會得到什麼**：主機整台壞掉時，手上仍有一份不超過一週的完整備份可以還原。

### 升級或大量修改資料之前

1. 按「立即備份」並確認。
2. 等「上次執行」變成「成功」、清單出現新的一份。
3. 再進行升級或修改。

**會得到什麼**：萬一出問題，可以還原到變更之前的狀態。

### 需要從備份還原時

1. 決定要用哪一份備份，下載下來（或直接使用主機上備份目錄裡的檔案）。
2. 交給部署人員，依「備份與還原操作手冊」停站後執行還原腳本。
3. 網站啟動後登入，確認資料回到備份當時。

**會得到什麼**：系統回到那份備份建立當時的狀態；之後新增或修改的資料不在其中，需要另外補回。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **快照** | 備份當下資料庫內容的完整複本；備份期間別人照常使用系統也不影響。 |
| **保留份數** | 最多留幾份備份；新的一份成功之後，超過的舊備份自動刪除。設為 0 表示不自動刪除。 |
| **還原** | 用備份把系統資料換回備份當時的樣子；必須停站、由部署人員執行還原腳本。 |
| **登入金鑰** | 網站用來加密登入資訊的金鑰；還原時會補回，所以還原後通常不必重新登入。 |
| **異地保存** | 把備份另外存一份在不同的主機或地點，主機整台壞掉時才救得回來。 |

以下頁面是否看得到、能不能操作，取決於你的權限設定。

## 七、常見問題

**問：備份時系統還能用嗎？**
答：可以。備份會先取得資料庫的快照再打包檔案，期間大家照常使用；資料很多時磁碟會比較忙一點。

**問：為什麼不能在畫面上還原？**
答：網站執行中替換資料庫檔很危險，可能把資料弄壞。還原必須先停站，由部署人員執行還原腳本，腳本會把還原前的資料改名保留，需要時可以回復。

**問：備份檔可以用一般的解壓縮軟體打開嗎？**
答：可以，它就是一般的 zip 檔，裡面有資料庫檔、各資料夾的檔案與一個說明檔 manifest.json。正因為沒有加密，請妥善保管。

**問：解壓縮後為什麼看不到某些資料夾？**
答：沒有檔案的資料夾不會出現在 zip 裡，例如還沒有任何附件時就看不到附件資料夾；每個資料夾有幾個檔，以這一頁「內容」欄的數字為準。AI 對話內容預設不備份。上傳與下載用的暫存資料夾不會備份，因為系統不會把要長期保存的資料放在那裡。

**問：備份目錄在哪裡？**
答：由部署人員在伺服器設定檔指定，不能放在對外提供檔案的目錄或網站目錄底下（系統啟動時會檢查）。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、備份檔名、「上次執行」的訊息與追蹤碼（最好截圖），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
