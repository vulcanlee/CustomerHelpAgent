# 角色管理

定義「角色」，也就是**一組權限加上一組預設團隊**，例如「業務人員」「唯讀主管」「資料維護員」。先把權限設在角色上，再到使用者管理把角色指派給人，就不必一個一個人設定。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：每個人能進哪些畫面、能按哪些按鈕，如果逐人設定會又亂又容易漏；依職務建立角色後，一次設定、大家共用。
- **誰會用到**：負責權限規劃的系統管理員；其他人進來只會看到「你沒有權限存取此頁面」，左側選單也不會出現這個項目。
- **它在系統的哪個位置**：左側選單「系統管理 › 帳號與權限 › 角色管理」。在流程上排在「使用者管理」之前：先建角色，再把角色指派給人。
- **開始前要準備**：列出這種職務需要用哪些畫面、每個畫面要不要能新增、修改、刪除；若要預設看某些團隊的資料，先確認團隊已經在「團隊清單」建好並啟用。
- **做完會得到**：一個可以在「使用者管理」指派的角色，擁有它的人只會看到被允許的畫面與按鈕，並自動多出這個角色的預設團隊。
- **它不做什麼**：不能在這裡指定哪些人擁有這個角色（那是「使用者管理」），也無法開放「系統管理」底下的畫面（那些只有管理員能用）。

## 一、功能摘要

在這一頁你可以：

- 新增、修改、刪除角色，用關鍵字搜尋（比對角色名稱）。0.9.95 起刪除可以還原（工具列的「顯示已刪除」）。
- 設定角色的「預設團隊」。
- 在權限設定裡逐頁勾選「（全部）」，或個別勾選「檢視」「新增」「編輯」「刪除」。
- 點表格欄位標題排序，用下方頁碼換頁（每頁 8 筆）。

新增、修改、刪除角色都會自動記在「稽核紀錄」。這個畫面沒有需要長時間處理的工作，不會出現持續顯示的處理進度視窗。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 系統管理員 | 依職務建立角色，控制每種人能進哪些畫面、能按哪些按鈕，以及預設看得到哪些團隊的資料。 |

### 角色怎麼影響使用者

| 層 | 和這一頁的關係 |
|---|---|
| 管理員 | 與這一頁無關。管理員是使用者管理裡的勾選，會略過所有權限檢查，不需要任何角色。 |
| 角色 | 權限設定決定擁有這個角色的人能做哪些動作。一個人有一個主要角色加上多個額外角色時，權限會**合併**：任何一個角色有勾，他就能用。 |
| 團隊 | 「預設團隊」會**加到**每一個擁有這個角色的人身上，和他在使用者管理直接綁定的團隊合在一起，決定他看得到哪些專案。 |

改完角色後，擁有這個角色的人不必重新登入，下一次切換頁面或重新整理瀏覽器時就會套用新權限與新的預設團隊。

### 關於「預設角色」

「預設角色」是系統內建的角色，擁有全部功能的權限；新增使用者時會預先選它，第一次用 Google 登入而自動建立的帳號預設也會套用它。它第一次建立時擁有全部功能的權限；你可以修改它的權限，系統重新啟動後**不會**被改回來。建議把它調整成「一般同事最基本需要的權限」，這樣新增的帳號與 Google 自動建立的帳號一開始就不會拿到過多權限。要注意：系統日後更新加入**新頁面**時，新頁面會自動加進「預設角色」，更新後請回來檢查一次。它不能被刪除（0.9.95 起），也不能改名（0.9.136 起）—— 系統是用這個名稱找它的。

### 建議的角色設定範例

| 角色 | 建議權限 |
|---|---|
| 業務人員 | 首頁；專案項目：檢視、新增、編輯；登出。預設團隊選自己的團隊，例如「業務一組」。 |
| 唯讀主管 | 首頁；專案項目：檢視；分類清單：檢視；團隊清單：檢視；登出。 |
| 資料維護員 | 首頁；專案項目：（全部）；分類清單：（全部）；團隊清單：（全部）；登出。 |

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 管理員 | 進入這一頁並使用所有功能。只有帳號勾選了「管理員」的人能進來，這個權限不在權限設定裡，無法透過角色開放。 |

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 決定某種職務能用哪些畫面、哪些按鈕，以及預設團隊 | 這一頁 |
| 把角色指派給人、查看某人有哪些角色 | 「使用者管理」 |
| 建立或啟用「預設團隊」下拉裡的團隊 | 「團隊清單」 |
| 查某個角色是誰、在什麼時候新增或修改的 | 「稽核紀錄」 |

## 四、建議這樣操作，會得到什麼

### 依職務建立一個新角色

1. 按工具列的「新增」，開啟「新增角色」視窗。
2. 輸入角色「名稱」，例如「業務人員」。
3. 需要時在「預設團隊」選擇團隊，例如「業務一組」。
4. 在「權限設定」勾選「首頁」「登出」，以及這個職務要用的畫面與動作。
5. 按「儲存」，在「確認儲存」視窗再按一次「儲存」。
6. 到「使用者管理」，把這個角色指派給相關同事。

**會得到什麼**：同一種職務的人權限一致，之後要調整只改角色一處，所有人一起生效。

### 讓主管只能看、不能改

1. 按「新增」，名稱填「唯讀主管」。
2. 在「專案管理功能」底下，只勾「專案項目」右邊的「檢視」，不要勾「（全部）」。
3. 勾選「首頁」與「登出」，「預設團隊」選主管要看的團隊，按「儲存」。
4. 到使用者管理，把主管的角色改成「唯讀主管」。

**會得到什麼**：主管看得到專案清單，但看不到「新增」「修改」「刪除」按鈕，不會不小心改到或刪掉資料。

> 業務一組的主管只需要看進度。管理員新增角色「唯讀主管」，勾「首頁」、「專案項目」的「檢視」與「登出」，預設團隊選「業務一組」，再到使用者管理把主管帳號 `user01` 的角色改成「唯讀主管」。主管切換一次頁面後，專案清單就只剩檢視用的畫面。

### 安全地刪除一個不用的角色

1. 到「使用者管理」用角色名稱搜尋，找出以它為主要角色的人（直接按「刪除」也可以：還有人使用時，訊息會列出他們的帳號）。
2. 把這些人的「角色」改成其他角色。
3. 回到這一頁按「刪除」並確認。

**會得到什麼**：角色移到「已刪除」；原本把它當成額外角色的人，會暫時失去這個角色帶來的權限與預設團隊。確定不再需要時，到「顯示已刪除」按「永久刪除」。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **角色** | 一組權限加上一組預設團隊，依職務建立後指派給人才會生效。 |
| **權限表** | 視窗下半部「權限設定」那一整塊勾選清單，一列是一個畫面，右邊是四種動作。 |
| **（全部）** | 勾了就等於該畫面的所有動作都能用，包含日後新增的動作。 |
| **檢視** | 進入畫面並看到資料的權限，是其他動作的前提。 |
| **預設團隊** | 擁有這個角色的人，都會自動多出這些團隊的資料可見範圍；留空代表不帶來任何團隊。 |
| **公開資料** | 沒有指定團隊的專案，所有能進專案頁的人都看得到。 |
| **預設角色** | 系統內建的角色，新帳號預設套用它。第一次建立時擁有全部權限；之後可以修改，重新啟動不會被改回，但系統更新加入的新頁面會自動加進來。 |
| **主要角色／額外角色** | 使用者管理裡「角色」與「額外角色」兩個欄位；兩者的權限會合併計算。 |

## 七、常見問題

**問：改了角色的權限，使用者什麼時候生效？**
答：不必重新登入。對方下一次切換頁面或重新整理瀏覽器時，就會套用新的權限與預設團隊。

**問：權限表裡找不到使用者管理、角色管理這些系統管理的畫面，是漏了嗎？**
答：不是。「系統管理」底下的畫面（帳號與權限、監控與診斷、AI 管理、系統設定與維運四組裡的各頁）刻意只開放給管理員，任何角色都勾不到。要讓某人使用這些畫面，只能在使用者管理把他設成管理員。

**問：只勾了「新增」或「編輯」，同事卻說連畫面都進不去？**
答：「檢視」是進入畫面的前提。請替那一項補勾「檢視」，或直接勾「（全部）」。

**問：按「刪除」後說「還有 N 位使用者以…為主要角色」？**
答：這個角色仍然是那些人的主要角色，刪掉的話他們每次換頁都會被登出，所以系統不讓你刪（0.9.95 起訊息會列出帳號；0.9.93～0.9.94 只顯示「刪除角色失敗。」）。請先到使用者管理把那些人的「角色」改掉，再回來刪除。

**問：刪錯了角色，可以救回來嗎？**
答：可以（0.9.95 起）。按工具列的「顯示已刪除」，找到那一個按「還原」即可，權限與預設團隊都和刪除前一樣，原本把它當額外角色的人也會重新拿到它的權限。按「永久刪除」之後就救不回來；沒有手動永久刪除的，刪除超過保留天數（預設 90 天，依系統設定）後，系統會自動永久刪除（0.9.97 起），請在那之前還原。已刪除的使用者若仍以它為主要角色，系統會等那些使用者先被永久刪除，才刪這個角色。

**問：出現「角色名稱已存在，無法新增。」？**
答：已經有同名的角色。請換一個名稱，或直接修改既有的角色。

**問：我修改了「預設角色」的權限，重新啟動後會被改回來嗎？**
答：不會（0.9.91 起）。你移除的權限會一直保持移除。唯一的例外是系統更新加入了**新頁面**：新頁面會自動加進「預設角色」，更新後請回來確認一次。「預設角色」不能刪除也不能改名，所以它不會被系統重新建立成擁有全部權限。

**問：取消勾選群組後，底下的權限為什麼還在？**
答：取消群組只會一併取消底下的「（全部）」，個別勾選的「檢視」「新增」「編輯」「刪除」會保留。要完全收回，請把那一項的四個動作也逐一取消後再儲存。

**問：按「儲存」存檔時出現「這筆資料在你編輯期間已被其他人修改或刪除」？**
答：你開啟編輯視窗之後，有其他人先存檔（或刪除）了同一筆資料，系統為了不讓你的存檔蓋掉對方的修改而擋了下來（0.9.93 起）。視窗會維持開啟，你填寫的內容還在：請先把要改的內容記下來，按「取消」關閉視窗、重新開啟同一筆，確認對方改了什麼之後再編輯一次。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
