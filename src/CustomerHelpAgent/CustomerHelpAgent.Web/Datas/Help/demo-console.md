# 展示控制台

售後 Agent 展示的準備台：一鍵**準備劇本**（重置資料、設定故障與模式、切換成示範帳號打開線上客服），也可以單獨開關**故障模擬**、**一鍵重置示範資料**、切換**即時／回放**、管理**錄製**與**金劇本**、**切換展示身分**，以及設定顧客頁**幕後面板**的預設。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：展示前要重置資料、開關故障、決定用真實模型還是回放、再登入成示範顧客，步驟多又容易漏；這一頁把它們收成一顆「準備此劇本」。
- **誰會用到**：負責展示售後 Agent 的系統管理員（展示者），以及事前錄製、挑選金劇本的人。
- **它在系統的哪個位置**：左側選單「系統管理 › 系統設定與維運 › 展示控制台」；使用者選單的「切換展示身分」也會帶到這一頁的身分切換區。
- **開始前要準備**：伺服器要開啟示範模式（由部署人員設定，正式環境不可開啟）；要用即時模式還需要設定好 AI 模型，否則只能用回放。
- **做完會得到**：示範資料回到初始狀態、故障與模式設定好，並以示範帳號的身分打開線上客服；每個變更都寫進稽核紀錄（`Demo.*`）。
- **它不做什麼**：不能新增或改寫劇本內容與顧客台詞；不能編輯錄製的內容；重置不會刪除紀錄、Token 用量與錄製；示範模式關閉時這一頁全部停用。

## 一、功能摘要

在這裡可以做什麼：

- 看目前的模式（即時或回放中）、啟用中的故障與上次重置的時間。
- 對十一個劇本（A 換尺碼、B 一句兩事、H 多 Agent：一句兩事、C 退貨逾期、D 物流催件、E 長期記憶、F1～F5 各種故障）按「準備此劇本」，一鍵完成重置、故障、模式與身分切換；多 Agent 劇本會直接以多 Agent 模式打開線上客服。
- 單獨開關七種故障模擬，或按「全部關閉」。
- 按「一鍵重置示範資料」把訂單、申請與 Agent 對話回到初始狀態。
- 切換即時／回放，回放時選擇要重播哪一段錄製。
- 在錄製清單把表現好的一段設為某個劇本的「金劇本」，或刪除不要的錄製（可勾選多筆）。
- 以四個示範帳號中的任一個身分檢視系統，之後用畫面上方的「回到展示者」切回。
- 設定顧客線上客服頁的幕後面板一開始是否打開。

## 四、建議這樣操作，會得到什麼

### 展示一個劇本

1. 在「即時／回放」選好模式：現場網路與 AI 服務穩定用即時，不想冒險就用回放。
2. 找到劇本卡片，按「準備此劇本」，看過確認窗的內容後按「重置並開始」。
3. 進到顧客的線上客服後，照卡片上「顧客說」的順序輸入，一邊用「講解重點」說明。
4. 展示完按畫面上方的「回到展示者」回到這一頁。

**會得到什麼**：每次展示都從相同的初始資料開始，故障與模式剛好是劇本需要的樣子。

### 事前準備金劇本

1. 模式選「即時」，對劇本 A 按「準備此劇本」，完整跑一次對話。
2. 回到這一頁，在錄製清單找到剛才那一段（最上面），按「設為金劇本」再點「A」。
3. 其他劇本照做。

**會得到什麼**：之後模式切到回放，「準備此劇本」會自動用這段金劇本，不再呼叫 AI 模型、不再產生費用。

### 單獨示範一種故障

1. 在「故障模擬」打開要示範的故障（例如「訂單系統逾時」）。
2. 用「身分切換」以 customer1 的身分到線上客服或我的訂單操作。
3. 示範完回到這一頁按「全部關閉」。

**會得到什麼**：同一個故障同時影響 Agent 與傳統頁面，可以對照兩邊的反應。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **劇本** | 一段預先設計好的展示情境：用哪個帳號、要開哪些故障、顧客依序說什麼、要講解哪些重點。 |
| **即時模式** | 顧客頁真的呼叫 AI 模型，會產生費用；每段對話自動錄製。 |
| **回放模式** | 顧客頁重播錄製時的模型回應，不呼叫 AI 模型、不產生費用；查訂單、建立申請等動作照常真的執行。 |
| **金劇本** | 某個劇本指定用來回放的那一段錄製；每個劇本最多一個。 |
| **故障模擬** | 刻意讓訂單、物流或規則服務出狀況，展示 Agent 遇到問題時如何停下來或轉人工。 |
| **展示者** | 從這一頁切換身分的管理員；切換後畫面上方可以「回到展示者」。 |

## 七、常見問題

**問：按了「準備此劇本」，之前的對話與申請到哪裡去了？**
答：重置會刪除所有業務資料（訂單、售後申請、Agent 對話、照片）並重建初始示範資料，所以都不見了；Agent 執行紀錄、Token 用量、AI 對話紀錄、錄製與稽核紀錄會保留，可以到對應頁面回看。

**問：模式選了回放，為什麼準備劇本時改成即時？**
答：那個劇本還沒有金劇本，沒有東西可以回放。確認窗會先告訴你；請先用即時跑一次，再在錄製清單把它設為金劇本。

**問：回放到一半停下來，說和錄製不一致，怎麼辦？**
答：回放只重播模型的回應，查訂單、查庫存等動作是真的執行；資料和錄製當時不同（例如庫存被改過、顧客輸入的話不一樣）就會停下來，不會編造結果。按「準備此劇本」重置後，照卡片上的台詞重新輸入；仍不一致就重新錄製金劇本。

**問：多 Agent 劇本（H）的金劇本要怎麼錄？劇本 E 可以回放嗎？**
答：錄製會記下當時是單一 Agent 還是多 Agent，回放時會以同一個模式重建，所以 H 要用「準備此劇本」（自動以多 Agent 模式打開）跑一次再設為金劇本。回放一次只播一段對話：劇本 E 跨三段對話，金劇本只涵蓋第一段（記住偏好），之後的開新對話與刪除記憶請用即時模式示範。

**問：故障開著忘記關，會影響別人嗎？**

**問：切換成示範帳號後，怎麼回來？**
