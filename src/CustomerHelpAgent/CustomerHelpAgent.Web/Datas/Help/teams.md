# 團隊清單

維護「團隊」這份清單：**新增、修改、停用、刪除團隊**，並排成**部門樹**（上層部門底下有下屬部門）。團隊決定**誰看得到哪些資料**：專案可以指定團隊，只有該團隊的成員看得到；上層部門的成員也看得到所有下屬部門的資料。

> 團隊會影響資料的可見範圍。改名會自動更新專案、分類與角色上的名稱；**停用、刪除不會**，動手前請先看第二段的說明。

### 一分鐘看懂這一頁

- **解決什麼問題**：不同小組的專案不想互相看到時，需要一個「小組」的單位來分權；這一頁就是用來建立與維護這些團隊。
- **誰會用到**：系統管理員，或負責組織架構與資料定義的人；一般同事只會在專案、分類的團隊下拉選用這裡建好的團隊。
- **它在系統的哪個位置**：左側選單「資料定義 › 團隊清單」；在流程上排在最前面：先建團隊，再到使用者管理、角色管理把人放進去，專案與分類才選得到它。
- **開始前要準備**：先想好團隊的正式名稱（建好後盡量不要改名），以及哪些同事要加入這個團隊。
- **做完會得到**：一個可在專案、分類、使用者與角色的團隊下拉中選到的團隊，用來限定專案的可見範圍與分類的使用範圍；排在某個上層部門底下時，上層的主管也看得到它的資料。
- **它不做什麼**：不能在這裡把人加進團隊（那是使用者管理或角色的預設團隊）；不畫組織圖，一個部門也只能有一個上層。

## 一、功能摘要

在這裡可以做什麼：

- 新增、修改、刪除團隊（依你的權限顯示按鈕）。
- 設定「上層部門」，清單以樹狀顯示，下屬部門收在上層底下，可展開收合。
- 改團隊名稱時，系統自動把專案、分類與角色預設團隊裡的舊名稱換成新名稱。
- 在清單上直接點「啟用」標籤停用團隊（會先確認），再點「停用」就重新啟用；停用的團隊不會再出現在各處的團隊下拉選單中。
- 為團隊填寫選填的「代號」與「描述」。
- 輸入關鍵字搜尋團隊的名稱、代號與描述。
- 點表格欄位標題排序，用下方頁碼換頁（每頁 8 筆）。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 系統管理員 | 建立與維護團隊，搭配使用者管理、角色管理決定每個人屬於哪些團隊。 |
| 資料定義負責人 | 依組織調整新增或停用團隊，讓專案與分類的團隊下拉保持正確。 |

### 團隊怎麼決定誰看得到資料

- 專案**沒有指定團隊** → 所有人都看得到（公開）。
- 專案**指定了團隊** → 屬於該團隊的使用者看得到，**該團隊所有上層部門的成員也看得到**。
- 使用者屬於哪些團隊＝在「使用者管理」直接綁定的團隊，**加上**他所有角色的「預設團隊」；他也看得到這些團隊所有下屬部門的資料。
- 反過來，下屬部門的成員**看不到**上層或同層其他部門的資料。

> 例：「總部」底下有「研發處」與「業務處」，「研發處」底下有「研發一部」。被加入「研發處」的主管看得到「研發處」與「研發一部」的專案，看不到「業務處」與只掛「總部」的專案；被加入「總部」的人全部看得到。
- 管理員看得到全部資料。

### 團隊是怎麼被記住的

專案、分類與角色的預設團隊，記錄的都是**團隊名稱這段文字**，不是代號；只有使用者管理裡「直接綁定」的團隊，是跟著團隊本身走的。這帶來三個容易踩到的後果：

| 動作 | 實際影響 |
|---|---|
| 改團隊名稱 | 使用者的直接綁定會跟著新名稱走；專案、分類、角色預設團隊上記的舊名稱**也會自動換成新名稱**（包含已刪除、之後可能還原的資料）。不能改成已刪除團隊用過的名稱。 |
| 停用團隊 | 只會從各處的團隊下拉選單消失；已經屬於這個團隊的人**仍然看得到**它的資料，不能當成收回權限使用。 |
| 刪除團隊 | **底下還有下屬部門時不能刪**，請先把下屬移到其他上層或刪除。除此之外**不會有任何使用中的警告**。刪除後使用者的直接綁定暫時失效（還原團隊就恢復）；專案、分類、角色預設團隊上記的團隊名稱不會被清掉，其中**角色預設團隊**仍會讓成員取得這個團隊（名稱比對，與 0.9.93 之前相同）。按「永久刪除」才會真正解除使用者的綁定。 |

改「代號」則沒有上述影響，代號目前只是給人看的備註，不參與任何可見範圍的比對。

這份團隊清單本身不做團隊過濾：只要有權限進入這一頁，就會看到所有團隊，包含已停用的。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 檢視 | 進入畫面、搜尋與排序、看資料。沒有檢視權限時會看到「你沒有權限存取此頁面」。 |
| 新增 | 看得到工具列的「新增」按鈕。 |
| 編輯 | 看得到每列的「修改」按鈕。 |
| 刪除 | 看得到每列的「刪除」按鈕、表格最左邊的勾選框與工具列的「刪除選取」，以及工具列的「顯示已刪除」（可還原或永久刪除已刪除的資料）。 |

> 權限設定在「角色管理」權限設定的「資料定義管理功能 › 團隊清單」底下；管理員看得到全部。建議只把新增、編輯、刪除權限開給負責資料分權的人。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 建立、改名、停用或刪除團隊 | 這一頁 |
| 把某位同事直接加入團隊 | 「使用者管理」（系統管理員） |
| 讓擁有某角色的人自動屬於某些團隊 | 「角色管理」的預設團隊（系統管理員） |
| 指定哪些專案屬於哪個團隊 | 「專案項目」 |
| 指定哪些團隊可以使用某個分類 | 「分類清單」 |

### 新增／修改團隊視窗

視窗只有「團隊資料」一區。

| 欄位 | 意思 | 範例 | 怎麼填或怎麼用 |
|---|---|---|---|
| 名稱 | 團隊名稱。 | 業務一組 | **必填**，最長 100 字元，全系統不可重複（比對時忽略前後空白與英文大小寫）。提示文字「請輸入團隊名稱」。修改時下方會提示「改名時，專案、分類與角色預設團隊裡的這個名稱會一起改。」 |
| 代號 | 給人看或對外整合用的短代號。 | SALES1 | 選填，最長 50 字元；有填時不可和其他團隊重複。提示文字「請輸入團隊代號（選填，有填則需唯一）」。 |
| 上層部門 | 這個部門屬於哪個部門底下。 | 業務處 | 選填，留空＝最上層（提示文字「（最上層）」）。選項不含自己和自己的下屬部門。下方說明「上層部門的成員看得到這個部門與它所有下屬部門的資料。自己和自己的下屬部門不在選項裡。」 |
| 描述 | 團隊說明。 | 「負責北區客戶的業務團隊」 | 選填，多行文字，最長 2000 字元。 |
| 啟用狀態 | 開關，顯示「啟用」或「停用」。 | 啟用 | 新增時預設「啟用」。停用後各處的團隊下拉選單就選不到它。 |

| 按鈕 | 按下後會做什麼 | 右下角會看到的提示 | 注意事項 |
|---|---|---|---|
| 視窗的「儲存」 | 先檢查欄位，再跳「確認儲存」：「確定要儲存這筆記錄嗎？」（「儲存」繼續、「再檢查」返回），接著檢查名稱與代號是否重複，通過後寫入。 | 「系統訊息」：「新增成功」（畫面頂端也會短暫出現「新增成功」）或「修改成功」；欄位沒填好時跳「驗證失敗」與原因，例如「團隊名稱 不可為空白」。 | 修改時一個欄位都沒動就按儲存，會顯示「沒有任何變更，未進行儲存。」並直接關閉。 |
| 視窗的「取消」、×、Esc | 關閉視窗。 | 無 | 有未儲存的修改時會跳「尚有未儲存的變更」：「離開後將遺失這些變更，確定要放棄嗎？」，選「放棄變更」關閉、選「繼續編輯」回去。點視窗外面不會關閉。 |

### 你可能看到的訊息

| 訊息 | 原因與處理 |
|---|---|
| 團隊名稱 不可為空白 | 名稱沒填，補上後再儲存。 |
| 名稱長度不可超過 100 字元／代號長度不可超過 50 字元／描述長度不可超過 2000 字元 | 內容太長，請縮短後再儲存。 |
| 團隊名稱已存在，無法新增。／團隊名稱已存在，無法修改。 | 已經有同名的團隊（包含已停用的），請換一個名稱。 |
| 團隊代號已存在，無法新增。／團隊代號已存在，無法修改。 | 代號和其他團隊重複，請換一個代號或留空。 |
| 團隊名稱已存在，無法儲存。／團隊代號已存在，無法儲存。 | 你和別人幾乎同時存了相同的名稱或代號，請換一個再存。 |
| 上層部門不能是自己。／上層部門不能是自己的下屬部門。 | 選的上層會形成循環，請換一個。 |
| 找不到選擇的上層部門，可能已被刪除。 | 你開窗之後，別人刪除了那個部門；重新開窗再選一次。 |
| 這個部門底下還有 N 個下屬部門，請先把它們移到其他上層部門或刪除後再刪除。 | 先處理下屬部門。 |
| 上層部門「X」也在已刪除清單中，請先還原上層部門。 | 在「顯示已刪除」清單先還原上層，再還原這個部門。 |
| 還有其他部門（含已刪除的）以它為上層部門，請先永久刪除那些部門。 | 永久刪除要從最底層開始。 |
| 已有同名的團隊「X」，無法還原。…／已有代號為「X」的團隊，無法還原。… | 刪除期間有人建立了同名或同代號的團隊；先把現有的那一筆改名或改代號，再還原。 |
| 找不到這個團隊，可能已被刪除。 | 點狀態標籤時，這個團隊已被別人刪除；按「重新整理」更新清單。 |
| 已刪除的團隊用過「X」這個名稱… | 改成這個名稱會讓那個已刪除團隊留下的資料被這個部門看到；換一個名稱，或先永久刪除那個團隊。 |
| 你沒有權限存取此頁面 | 你的角色沒有團隊清單的檢視權限，請洽系統管理員。 |
| 已刪除 S 筆，F 筆未刪除：… | 「刪除選取」時有幾筆刪不掉，每筆後面寫著原因（例如底下還有下屬部門、已被別人刪除）；其他筆已經刪除。 |

這個畫面沒有長時間處理的工作，不會出現持續顯示的處理進度視窗。一般提示幾秒後會自動消失。

## 四、建議這樣操作，會得到什麼

### 成立一個新團隊

1. 按工具列的「新增」，輸入正式的團隊名稱；需要時再填代號與描述。
2. 啟用狀態維持「啟用」，按「儲存」，在「確認儲存」選「儲存」。
3. 請系統管理員到使用者管理替成員綁定這個團隊，或在角色管理把它設為某角色的預設團隊。

**會得到什麼**：新團隊出現在專案、分類、使用者與角色的團隊下拉選單中，被綁定的成員可以看到指定了這個團隊的專案。

> 公司新成立「業務一組」。管理員先在這一頁新增團隊「業務一組」、代號 `SALES1`，再到使用者管理把王小明加入這個團隊。之後王小明建立專案「官網改版」時，團隊選「業務一組」，就只有同組的同事看得到這筆專案。

### 建立部門樹

1. 先新增最上層的部門（例如「總部」），上層部門留空。
2. 再新增下屬部門（例如「研發處」「業務處」），「上層部門」選「總部」；更下一層依此類推。
3. 請系統管理員把各部門主管加入他負責的那個部門。

**會得到什麼**：清單變成樹狀；主管看得到自己部門與所有下屬部門的專案，同層的部門彼此看不到。

### 團隊要改名

1. 在該列按「修改」，把名稱改成新名稱並儲存。

**會得到什麼**：專案、分類與角色預設團隊裡的舊名稱一起換成新名稱，可見範圍維持不變；稽核紀錄會寫下更新了幾筆。

### 團隊解散，不再使用

1. 點該列的「啟用」標籤，在「停用團隊」確認窗按「停用」（也可以按「修改」把啟用狀態切到「停用」並儲存）。
2. 若要讓成員真的看不到該團隊的資料，請系統管理員到使用者管理與角色管理移除這個團隊的綁定。

**會得到什麼**：團隊不再出現在下拉選單中；搭配第二步，原成員也不再看得到只掛了這個團隊的專案。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **團隊** | 系統劃分資料可見範圍的單位，專案指定團隊後只有該團隊成員看得到。 |
| **團隊名稱** | 各處用來比對可見範圍的文字；改名時系統會自動更新既有的專案、分類與角色。 |
| **上層部門／下屬部門** | 部門樹的上下關係。上層部門的成員看得到所有下屬部門的資料，反過來不行。 |
| **代號** | 選填的短代號，目前只是備註，不影響任何可見範圍。 |
| **停用** | 讓團隊從下拉選單消失，但不會收回已綁定成員的可見範圍。 |
| **直接綁定** | 在使用者管理裡把團隊指定給某個人，這種綁定會跟著團隊改名；刪除團隊時暫時失效、還原後恢復，永久刪除時才解除。 |
| **預設團隊** | 在角色上設定的團隊，擁有該角色的人會自動屬於這些團隊。 |
| **公開** | 專案沒有指定任何團隊，所有使用者都看得到。 |

## 七、常見問題

**問：我把團隊停用了，為什麼成員還看得到它的專案？**
答：停用只會讓團隊從下拉選單消失，不會收回可見範圍。要讓成員看不到，請系統管理員在使用者管理與角色管理中移除這個團隊。

**問：主管看得到下屬部門的資料嗎？**
答：看得到。把主管加入他負責的部門，就看得到那個部門與它底下所有部門的資料；同層或上層的部門看不到。

**問：為什麼刪不掉某個部門？**
答：它底下還有下屬部門。請先把下屬部門的「上層部門」改到別處，或先刪除下屬部門。

**問：代號要不要填？填了有什麼作用？**
答：代號是選填的，目前只是給人看或對外整合用的備註，不影響誰看得到哪些資料。有填時不可和其他團隊重複。

**問：刪除團隊前要注意什麼？**
答：刪除確認窗不會提醒你是否還有專案、分類或角色在用這個團隊。0.9.94 起刪除可以還原，但刪除期間成員會看不到只標記這個團隊的專案；請先用專案項目的「團隊過濾」盤點，不確定時改用「停用」。

**問：看不到「新增」「修改」或「刪除」按鈕？**
答：你的角色缺少「團隊清單」的對應權限（新增、編輯或刪除），請洽系統管理員調整角色。

**問：按「儲存」存檔時出現「這筆資料在你編輯期間已被其他人修改或刪除」？**
答：你開啟編輯視窗之後，有其他人先存檔（或刪除）了同一筆資料，系統為了不讓你的存檔蓋掉對方的修改而擋了下來（0.9.93 起）。視窗會維持開啟，你填寫的內容還在：請先把要改的內容記下來，按「取消」關閉視窗、重新開啟同一筆，確認對方改了什麼之後再編輯一次。

**問：刪錯了團隊，可以救回來嗎？**
答：可以（0.9.94 起）。刪除只是把資料移到「已刪除」：按工具列的「顯示已刪除」，找到那一筆按「還原」即可，內容與刪除前相同，使用者的直接綁定也會一起恢復。在「已刪除」清單裡按「永久刪除」之後就救不回來；沒有手動永久刪除的，刪除超過保留天數（預設 90 天，依系統設定）後，系統會自動永久刪除（0.9.97 起），請在那之前還原。看不到「顯示已刪除」按鈕表示你沒有刪除權限，請洽系統管理員。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
