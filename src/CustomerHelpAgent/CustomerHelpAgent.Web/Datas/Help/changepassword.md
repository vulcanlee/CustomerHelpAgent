# 變更密碼

**修改自己的登入密碼**：先輸入目前密碼證明是本人，再設定一組符合密碼規則的新密碼。右上角使用者選單的「變更密碼」也是開這一頁。

> 如果管理員要求你先變更密碼，或你的密碼已經到期，系統會把你帶到這一頁，改掉之前不能使用其他頁面。

### 一分鐘看懂這一頁

- **解決什麼問題**：定期更換密碼、懷疑密碼外洩，或管理員給了你一組初始密碼時，讓你自行改成只有自己知道的密碼。
- **誰會用到**：所有使用帳號密碼登入的人；系統預設的開發帳號 `support` 例外，不能在這裡改密碼。
- **它在系統的哪個位置**：不在左側選單裡。從右上角使用者選單的「變更密碼」進入；被要求變更或密碼到期時，系統也會自動帶你來。
- **開始前要準備**：你必須記得**目前的密碼**；另外先想好新密碼 —— 新密碼欄位下方會寫出目前的規則（預設至少 8 個字元、要有英文字母與數字，而且不能和最近 3 次用過的密碼相同）。
- **做完會得到**：新密碼立即生效，下次登入時請改用新密碼；你目前的登入狀態會維持，不需要重新登入。
- **它不做什麼**：不能替別人改密碼，也不能在忘記目前密碼時使用；那兩種情況分別要找系統管理員，或使用登入頁的「忘記密碼？」。

## 一、功能摘要

在這裡可以做什麼：

- 輸入目前密碼、新密碼與確認新密碼，驗證通過後立即更新你的登入密碼，成功後回到首頁。
- 新密碼欄位下方顯示目前的密碼規則；不符合時會告訴你差在哪裡。
- 被要求變更或密碼到期的人，改好之後即可恢復正常使用各頁面。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 剛拿到帳號的同事 | 把管理員給的初始密碼改成只有自己知道的密碼（管理員通常會勾選「下次登入須變更密碼」）。 |
| 所有使用帳號密碼登入的人 | 定期更換密碼、密碼快到期時，或懷疑密碼外洩時立即更換。 |

### 系統怎麼檢查

1. 先確認你輸入的**目前密碼**正確。
2. 檢查新密碼有沒有填、和確認新密碼是否完全相同。
3. 檢查新密碼是否符合**密碼規則**（字數、要包含的字元種類）。
4. 檢查新密碼是否和你**最近幾次用過的密碼**相同（含目前這組）。
5. 全部通過後才把新密碼存起來。

密碼規則由系統管理員在「系統參數」的「密碼與登入」設定，所以不同公司可能不一樣；以新密碼欄位下方顯示的為準。

### 被系統強制帶到這一頁

以下兩種情況，登入後不論點哪一頁，系統都會把你帶回這一頁，直到你改好密碼為止。頁面上方會用藍色說明框告訴你是哪一種：

| 說明框文字 | 原因 |
|---|---|
| 系統管理員要求你先變更密碼，才能繼續使用系統。 | 管理員建立你的帳號、替你設定了密碼，或特別要求你換密碼。 |
| 你的密碼已到期，請設定新密碼後繼續使用系統。 | 系統設定了密碼有效天數，你的密碼已經超過期限。到期前 7 天內，右上角的鈴鐺會提醒你（同一個到期日只提醒一次）。 |

### 改完之後

變更密碼後，你在這台電腦上的登入狀態會維持（畫面會很快地重新整理一次）；**其他裝置上的登入一律失效**：已開著的頁面在下一次切換頁面時被登出，其他程式透過 API 的登入最晚 1 小時內失效。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 不需要特別權限 | 只要已經登入，都可以進入這一頁修改自己的密碼。 |
| `support` 帳號 | 不能變更密碼，畫面只會顯示禁止變更的提示。 |

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 記得目前密碼，想改成新密碼 | 這一頁（右上角使用者選單的「變更密碼」） |
| 忘記目前密碼 | 登出後在登入頁點「忘記密碼？」；沒有這個連結時請找系統管理員 |
| 替其他同事重設密碼、解除登入鎖定 | 系統管理員在「使用者管理」處理 |

## 三、畫面上有哪些按鈕、各自做什麼

### 這一頁的欄位

標題「變更密碼」下方會顯示你目前登入的帳號，方便確認改的是哪一個帳號。被要求變更時，帳號下方還有一個藍色說明框寫出原因。這一頁不在左側選單裡，頁首的頁面標題顯示「變更密碼」。

| 欄位 | 意思 | 範例 | 怎麼填或怎麼用 |
|---|---|---|---|
| 目前密碼 | 你現在用來登入的密碼。 | （你目前的密碼） | **必填**。提示文字「請輸入目前密碼」；打錯時無法變更。 |
| 新密碼 | 要改成的新密碼。 | Spring2026go | **必填**。提示文字「請輸入新密碼」；欄位下方灰字是目前的密碼規則，例如「至少 8 個字元，需包含英文字母、數字，不可與最近 3 次用過的密碼相同。」 |
| 確認新密碼 | 再輸入一次新密碼，避免打錯。 | （與新密碼相同） | **必填**。提示文字「請再次輸入新密碼」；必須和新密碼完全相同。 |

### 這一頁的按鈕

| 按鈕 | 按下後會做什麼 | 右下角會看到的提示 | 注意事項 |
|---|---|---|---|
| 儲存 | 檢查欄位並送出變更，成功後回到首頁。 | 成功時畫面頂端短暫出現「密碼已變更。」；失敗時右下角出現「系統訊息」與原因（見下方訊息表），可按「複製」把內容放進剪貼簿。 | 欄位沒填或兩次新密碼不同時，欄位下方也會顯示原因。送出期間按鈕會轉圈，請勿重複點按。 |
| 取消 | 不做任何變更，直接回到首頁。 | 無 | 如果你是被要求變更或密碼已到期，回到首頁後又會被帶回這一頁。 |

若你登入的是 `support` 帳號，這一頁不會出現表單，只會顯示「系統預設開發帳號 support 禁止變更密碼」。

### 你可能看到的訊息

| 訊息 | 原因與處理 |
|---|---|
| 目前密碼 不可為空白／新密碼 不可為空白／確認新密碼 不可為空白 | 必填欄位沒填，補上後再按「儲存」。 |
| 新密碼與確認密碼不一致 | 兩次輸入的新密碼不同，請重新輸入。 |
| 請確認密碼欄位皆已正確填寫。 | 按「儲存」時有欄位沒填或兩次新密碼不同，右下角以「驗證失敗」提示；照欄位下方的原因修正後再按「儲存」。 |
| 目前密碼不正確。 | 目前密碼打錯，請確認大小寫與輸入法後重新輸入。 |
| 密碼不符合規則：至少 8 個字元、要有數字。 | 新密碼不符合規則，冒號後面列出所有沒做到的項目（例如還可能有「要有英文字母」「要有大寫英文字母」「要有符號」）。照著補齊即可。 |
| 新密碼不可與最近使用過的密碼相同。 | 新密碼和你目前或最近幾次用過的密碼一樣，請換一組沒用過的。 |
| 變更密碼時發生未預期的錯誤。（錯誤追蹤碼：…） | 系統處理時出錯，請稍後再試；持續發生請按「複製」把訊息與追蹤碼一起回報系統管理員。 |

### 右下角的處理進度提示

這個畫面沒有長時間處理的工作，不會出現持續顯示的處理進度視窗；錯誤提示會一直留著，右下有「複製」按鈕，按 X 才關閉。

## 四、建議這樣操作，會得到什麼

### 第一次登入，被要求變更初始密碼

1. 用管理員給你的帳號（例如 `user01`）與初始密碼登入，系統自動帶你到這一頁，上方說明框寫著「系統管理員要求你先變更密碼…」。
2. 在「目前密碼」輸入管理員給你的初始密碼。
3. 看一下新密碼欄位下方的規則，在「新密碼」與「確認新密碼」輸入同一組符合規則的新密碼。
4. 按「儲存」。

**會得到什麼**：看到「密碼已變更。」後回到首頁，之後可以正常使用各個頁面；下次登入請用新密碼。

### 鈴鐺提醒密碼快到期

1. 右上角的鈴鐺出現「密碼將於 … 到期」的通知，點它會帶你到這一頁。
2. 輸入目前密碼與一組沒用過的新密碼，按「儲存」。

**會得到什麼**：密碼的有效期限從今天重新計算，到期後也不會被強制帶來這一頁。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **目前密碼** | 你現在用來登入的密碼，變更前必須輸入正確才能繼續。 |
| **密碼規則** | 新密碼至少要幾個字、要包含哪些種類的字元；由系統管理員設定，顯示在新密碼欄位下方。 |
| **最近用過的密碼** | 系統會記住你最近幾次的密碼（只存加密後的結果，看不到原文），新密碼不能和它們相同。 |
| **下次登入須變更密碼** | 管理員在你的帳號上勾選的要求；勾選後你登入時會先被帶到這一頁。 |
| **密碼到期** | 系統設定了密碼有效天數時，超過天數就必須換新密碼。 |
| **使用者選單** | 畫面右上角顯示你名稱與圓形縮寫的選單，裡面有「個人資料」「變更密碼」「關於」「登出」。 |
| **`support` 帳號** | 系統預設的開發帳號，密碼由系統設定決定，不能在這裡變更。 |

## 六、相關頁面

以下頁面是否看得到、能不能操作，取決於你的權限設定。

- [首頁](/App)：這一頁按「儲存」成功或按「取消」後都會回到首頁。
- [個人資料](/Profile)：看密碼上次變更與到期的時間，以及自己最近的登入紀錄。
- [使用者管理](/myusers)：忘記目前密碼又無法自助重設、或帳號被鎖定時，系統管理員可以在這裡替你設定新密碼或解鎖。
- [系統參數](/system-parameters)：系統管理員在「密碼與登入」設定密碼規則與有效天數。

## 七、常見問題

**問：我忘記目前的密碼，怎麼辦？**
答：這一頁一定要輸入正確的目前密碼。請先登出，在登入頁點「忘記密碼？」自助重設；如果登入頁沒有這個連結，代表系統沒有啟用寄信，請聯絡系統管理員替你重設。

**問：為什麼我點任何頁面都會被帶回變更密碼頁？**
答：因為管理員要求你先變更密碼，或你的密碼已經到期；頁面上方的藍色說明框會寫出原因。改好之後就會恢復正常。

**問：我想把密碼改回以前用過的那一組，為什麼不行？**
答：系統不允許重複使用最近幾次的密碼（次數由管理員設定），這是為了避免外洩過的密碼又被拿來用。請換一組新的。

**問：我是用 Google 登入的，為什麼一直顯示目前密碼不正確？**
答：用 Google 登入建立的帳號沒有系統內的密碼，所以無法在這裡變更。若需要改用帳號密碼登入，請洽系統管理員在使用者管理替你設定密碼。

**問：改完密碼後，其他電腦上的登入會被登出嗎？**
答：會。其他裝置上已開著的頁面在下一次切換頁面時會回到登入頁，要用新密碼重新登入；你正在用的這台不受影響。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
