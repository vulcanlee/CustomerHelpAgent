# 資料保留與清理

一頁看完系統裡**每一種會自動刪除的資料**：現在有多少、佔多少空間、最舊到什麼時候、保留多久、下一次自動清理會刪掉多少，以及負責清理的排程什麼時候跑。需要時可以**立即清理**（照保留規則）、**自訂清除**（自己決定只留最近幾天或刪到哪一天），或按**前往**到該資料的頁面挑選個別紀錄刪除。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：保留天數在「系統參數」、清理排程在「排程作業」、手動刪除散在各頁，要回答「資料留多久、空間被誰吃掉、自動清理有沒有在跑」得開好幾頁；這一頁把它們放在一起。
- **誰會用到**：負責維運的系統管理員，以及要說明資料保留政策的人。
- **它在系統的哪個位置**：左側選單「系統管理 › 系統設定與維運 › 資料保留與清理」。
- **開始前要準備**：不用準備。要改保留天數時，先想好要留多久（縮短後，下一次清理就會刪掉超過的資料，無法復原）。
- **做完會得到**：知道每種資料的量與保留規則；按「立即清理」後，超過保留期限的資料在背景刪除，稽核紀錄寫 `Job.Trigger` 與各自的 `*.AutoPurge`；「自訂清除」完成後右下角告訴你刪了幾筆，稽核紀錄寫各自的 `*.Purge`。
- **它不做什麼**：不能在這一頁改保留天數（按「修改」到系統參數頁；「自訂清除」只影響那一次）；不能在這一頁挑選個別紀錄刪除（按「前往」到各頁）；系統備份、日誌檔與公告沒有「立即清理」與「自訂清除」。

## 一、功能摘要

在這裡可以做什麼：

- 看每種資料的目前數量、檔案佔用空間、最舊一筆的時間。
- 看保留規則（例如「保留 365 天」「90 天未再發生就刪除」）與下一次自動清理會刪掉多少。
- 看負責清理的排程：多久跑一次、有沒有停用、上次執行的時間與結果、下次執行的時間。
- 按「立即清理」照目前的保留規則馬上清一次。
- 按「自訂清除」自己選「只留最近 N 天」或「刪除某一天之前」，先看會刪幾筆再清除（0.9.134 起）。
- 按「前往」到可以細部刪除的頁面；按保留規則旁的「修改」到系統參數頁。

### 右下角的處理進度提示

清理在背景執行，不會出現持續顯示的處理進度視窗；清理進行中，頁面每 5 秒自動更新，直到「上次」出現這次的結果為止。

## 四、建議這樣操作，會得到什麼

### 磁碟或資料庫變大時

1. 打開這一頁，看「目前數量」與「檔案空間」哪一列最大。
2. 看那一列的「保留規則」是否太長；需要時按「修改」到系統參數頁縮短。
3. 回到這一頁按「重新整理」，確認「下次會清掉」的數量，再按「立即清理」。

**會得到什麼**：超過新保留期限的資料在背景刪掉，空間在清理完成後釋放（資料庫檔案本身的大小要壓縮後才會變小，見「資料庫用量」）。

### 每月巡檢自動清理

1. 確認每一列「自動清理」的「上次」是成功、時間是最近一次排程。
2. 確認「下次會清掉」沒有一直累積（累積代表排程沒在跑或一直失敗）。
3. 有失敗時到「排程作業」看那個作業的執行紀錄。

**會得到什麼**：及早發現自動清理停擺，避免資料無限累積。

### 空間不夠，想先多清一些（不改保留天數）

1. 按那一列的「自訂清除」。
2. 選「只留最近 N 天」填一個比保留天數小的數字，或選一個日期，看「會刪除 N 筆」。
3. 按「清除」並確認。

**會得到什麼**：這一次多清掉一些舊資料，之後自動清理仍照系統參數的保留天數進行。

### 要刪除特定幾筆而不是整批過期的

1. 按那一列的「前往」。
2. 在該頁勾選、依日期批次清除，或在「顯示已刪除」裡永久刪除。

**會得到什麼**：只刪掉你挑的資料，其他照保留規則保留。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **保留天數** | 資料留多久；超過就會在下一次自動清理時刪除。設為 0 表示不自動刪除。 |
| **自動清理** | 每天固定時間執行的排程作業，依保留規則刪掉過期的資料與相關檔案。 |
| **立即清理** | 不等排程，現在就依目前的保留規則清一次；和「排程作業」頁的「立即執行」相同。 |
| **永久刪除** | 已刪除（可還原）的資料真的從系統移除，之後無法還原。 |
| **下次會清掉** | 已經超過保留期限、還沒被清掉的數量；排程正常時，每次清理後會回到 0 附近。 |

## 七、常見問題

**問：「下次會清掉」一直不是 0，是不是壞了？**
答：先看那一列「自動清理」的「上次」：如果是失敗，到「排程作業」看執行紀錄；如果排程已停用，下次會顯示「不會自動執行」。已刪除資料的數字是「最多」，support 帳號、預設角色、仍在使用的角色與還有下屬的部門會一直留著，這是正常的。

**問：按了「立即清理」，數字為什麼沒有馬上變？**
答：清理在背景進行，頁面每 5 秒自動更新；資料很多時要等一下。完成後「上次」會顯示這次刪掉幾筆。

**問：可以在這一頁直接改保留天數嗎？**
答：不行，保留天數只在「系統參數」修改，按保留規則旁的「修改」就會到對應的分類。這樣設定只有一個地方，不會兩邊不一致。只想這一次多清一些，請用「自訂清除」，它不會改到保留天數。

**問：「立即清理」和「自訂清除」差在哪？**
答：「立即清理」照系統參數的保留規則跑一次排程（在背景執行，已刪除的五種一起清）；「自訂清除」用你這次選的天數或日期，在這一頁立刻刪除，已刪除資料只清那一種。兩者都無法復原。

**問：為什麼系統備份沒有「立即清理」？**
答：舊備份是在「新備份成功之後」才刪除，避免手上一份備份都沒有；要刪舊備份請按「前往」到系統備份頁勾選刪除。

**問：檔案空間顯示「未設定」是什麼意思？**
答：伺服器設定檔沒有設定這個資料夾，系統也就不會寫檔到那裡。如有疑問請洽部署人員。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、哪一列、畫面上的訊息（最好截圖），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
