# Agent 執行紀錄

客服與店家在這裡**回頭查看線上客服 Agent 的每一輪執行**：列出每一輪的時間、顧客、為什麼停下來、呼叫了幾次模型與工具，點開就能看到和顧客「幕後面板」相同的逐步時間軸。

> 這一頁是唯讀的稽核與教學用紀錄：只能看，不能修改，也不能刪除。

### 一分鐘看懂這一頁

- **解決什麼問題**：Agent 做了什麼決定、查了哪些資料、為什麼停下來，事後都能在這裡逐步還原，方便檢查與說明。
- **誰會用到**：負責售後的客服人員與店家管理者；需要角色有「售後服務 › Agent 執行紀錄」的權限才進得來。
- **它在系統的哪個位置**：左側選單「售後服務 › Agent 執行紀錄」；顧客端對應的是商店「線上客服」旁的幕後面板。
- **開始前要準備**：不需要準備什麼，但要有顧客用過「線上客服」，這裡才會有紀錄。
- **做完會得到**：看懂某一輪 Agent 每一步的來源（對話、資料庫、規則、記憶、程式）與白話說明，必要時展開原始資料。
- **它不做什麼**：不會重播或重跑 Agent、不能修改或刪除紀錄，也不會處理售後申請（那是「售後審核」的工作）。

## 一、功能摘要

在這裡可以做什麼：

- 依時間由新到舊列出每一輪 Agent 執行，看顧客、停止原因與模型、工具的呼叫次數。
- 點一下任一列，打開「Agent 執行步驟」視窗，看這一輪的完整步驟時間軸。
- 在視窗裡對有原始資料的步驟按「看原始資料」，展開當時的 JSON 內容。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 客服人員 | 顧客反映 Agent 回答怪怪的時候，回頭看它當時查了什麼、為什麼這樣回。 |
| 店家管理者 | 抽查 Agent 的行為是否符合售後規則，作為調整規則或提示詞的依據。 |
| 系統管理員 | 看得到全部，協助排除「Agent 為什麼停下來」之類的問題。 |

### 一輪執行是什麼

| 名詞 | 意思 |
|---|---|
| 一輪 | 顧客送出一則訊息（或按下確認）後，Agent 從開始處理到停下來的整個過程。 |
| 停止原因 | 這一輪為什麼停下來，例如已回覆、等待顧客確認、已達步數上限；由程式判定，用白話寫出。 |
| 步驟 | 這一輪裡的每個動作：收到顧客訊息、呼叫模型、查資料、程式檢查、顯示確認卡等。 |

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 檢視 | 進入畫面、換頁、打開步驟視窗、展開原始資料。沒有檢視權限時會看到「你沒有權限存取此頁面」。 |

> 權限設定在「角色管理」權限設定的「售後服務 › Agent 執行紀錄」底下；管理員看得到全部。這一頁沒有新增、修改、刪除的動作。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 回頭查看 Agent 每一輪做了什麼 | 這一頁 |
| 處理顧客送來的售後申請 | 「售後審核」 |
| 查看或調整售後規則 | 「售後規則管理」 |

## 四、建議這樣操作，會得到什麼

### 找出 Agent 為什麼停下來

1. 在清單找到顧客反映問題的那一輪，先看「停止原因」欄。
2. 點一下那一列，打開步驟視窗，從上往下看每一步。
3. 對可疑的步驟按「看原始資料」，確認當時查到的內容。

**會得到什麼**：知道 Agent 是正常等顧客確認、被程式因為步數或失敗次數擋下，還是模型呼叫失敗。

> 王大同反映「客服問到一半就不理我了」。客服在清單找到他那一輪，停止原因寫著「程式停止本輪：工具連續失敗」；點開視窗，看到查詢訂單的步驟連續逾時，於是通知系統管理員檢查服務狀態。

## 七、常見問題

**問：為什麼清單是空的？**
答：還沒有顧客使用過「線上客服」。顧客送出第一則訊息後，這裡就會出現紀錄。

**問：可以刪除或修改某一筆紀錄嗎？**
答：不行。這一頁是唯讀的，紀錄由系統寫入，無法在這裡變更。

**問：「模式」欄的「回放」是什麼？**
答：展示時可以重播事先錄好的模型回應（不呼叫模型、不計 Token）。這種回合會標「回放」，步驟視窗裡的模型步驟也寫「回放：使用錄製 #N 的回應（未呼叫模型）」，和真正呼叫模型的回合分得出來。

**問：停止原因寫「進行中或未正常結束」是什麼意思？**
答：這一輪沒有留下結束的記錄，可能還在處理中，也可能處理到一半服務被中斷。

**問：步驟視窗裡看得到顧客的姓名、地址或電話嗎？**
答：模型本身看不到收件人姓名、地址與手機，工具也不會把這些資料交給它。清單上的顧客姓名是給客服辨識是誰用的。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的紀錄時間與顧客、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
