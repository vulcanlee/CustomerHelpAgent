# 個人資料

看自己的**帳號資料、角色與團隊、密碼與兩步驟驗證狀態、最近的登入紀錄**，並可以修改自己的**姓名**。

> 這一頁只看得到、只改得到你自己的資料。

### 一分鐘看懂這一頁

- **解決什麼問題**：以前想知道「我是什麼角色、看得到哪些團隊、密碼什麼時候到期、最近有沒有人用我的帳號登入」都得問管理員；現在自己就能查，姓名寫錯也能自己改。
- **誰會用到**：所有登入的人；想修正自己的姓名、確認自己的權限範圍，或檢查帳號安全時使用。
- **它在系統的哪個位置**：不在左側選單裡。點右上角你的名稱，選「個人資料」。
- **開始前要準備**：不需要準備什麼；要改姓名時想好正確的寫法即可。
- **做完會得到**：改好姓名按「儲存」，右上角的名稱與圓形縮寫立即更新。
- **它不做什麼**：不能改 Email、角色、團隊、管理員或啟用狀態（這些由系統管理員在「使用者管理」設定）；不能上傳大頭照；改密碼請按「變更密碼」到另一頁。

## 一、功能摘要

在這裡可以做什麼：

- 修改自己的姓名（必填）。
- 查看帳號、Email（唯讀）、自己的角色與團隊。
- 查看密碼上次變更的時間、什麼時候到期，以及是否被要求變更；按「變更密碼」前往變更密碼頁。
- 查看兩步驟驗證是否已開啟；按「設定兩步驟驗證」（或「管理兩步驟驗證」）前往設定頁。
- 查看自己最近 20 筆登入、登入失敗與登出紀錄。
- 修改姓名會記在「稽核紀錄」（動作 `User.ProfileUpdate`）。清單上的摘要不記姓名；改前與改後的姓名只記在明細的「詳細內容」，只有管理員看得到（0.9.131 起）。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 一般同事 | 姓名打錯時自己修正；確認自己的角色與團隊；看密碼什麼時候到期。 |
| 擔心帳號安全的人 | 看最近的登入紀錄，發現不是自己做的登入或失敗，馬上換密碼並通知管理員。 |

### 頁面上的五個區塊

| 區塊 | 內容 |
|---|---|
| 姓名與 Email | 上方是圓形縮寫、姓名與帳號；下方可以改姓名，Email 只能看。 |
| 角色與團隊 | 你所有的角色（主要角色與額外角色）、你所屬的團隊（直接加入的，加上角色預設的），以及因此也看得到的「下屬部門」（部門樹，沒有時不顯示這一列）。沒有團隊時顯示「（沒有團隊，只看得到沒有指定團隊的公開資料）」。 |
| 密碼 | 上次變更、到期（沒有設定有效天數時顯示「不會到期」）、是否被管理員要求變更。用 Google 登入、沒有系統密碼的人只會看到一行說明。 |
| 兩步驟驗證 | 「已啟用」或「未啟用」與前往設定頁的按鈕。用 Google 登入、沒有系統密碼的人沒有這個區塊。 |
| 最近 20 筆登入紀錄 | 時間、動作（登入、登入失敗、Google 登入、Google 登入失敗、登出、帳號停用中嘗試登入、連續輸錯，帳號被鎖定、兩步驟驗證碼錯誤、其他地方變更了帳號，被登出…）、來源 IP（0.9.123 起；0.9.117 之前的舊紀錄顯示「—」）與結果，新的在上面。 |

### 圓形縮寫

右上角與這一頁上方的圓形縮寫取自姓名：中文取第一個字（王小明 →「王」）；英文姓名取第一個字與最後一個字的字首（John Smith →「JS」）。

|---|---|
| 不需要特別權限 | 只要已經登入，都可以進入這一頁，看與改自己的資料。 |

## 四、建議這樣操作，會得到什麼

### 修正打錯的姓名

1. 點右上角你的名稱，選「個人資料」。
2. 在「姓名」改成正確的寫法，按「儲存」。

**會得到什麼**：右下角出現「已更新姓名」，右上角的名稱與圓形縮寫立即換成新的。

### 檢查帳號有沒有被別人用過

1. 打開「個人資料」，看「最近 20 筆登入紀錄」。
2. 如果有你不記得的登入、來自陌生 IP 的紀錄，或連續的「登入失敗」，按「變更密碼」換一組新密碼，並把時間與 IP 告訴系統管理員。

**會得到什麼**：舊密碼立即失效；管理員可以到「稽核紀錄」查更多細節。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **圓形縮寫** | 代替大頭照的圓形標記，取自你的姓名。 |
| **角色** | 決定你能用哪些畫面與功能；可以有一個主要角色加上幾個額外角色。 |
| **團隊** | 決定你看得到哪些團隊的資料。 |
| **下屬部門** | 你所屬團隊底下的部門；你也看得到它們的資料。 |
| **密碼到期** | 系統設定了密碼有效天數時，超過天數就必須換新密碼；到期前 7 天鈴鐺會提醒你。 |
| **登入紀錄** | 系統記下的每一次登入、登入失敗與登出；這裡只列你自己的最近 20 筆。 |

## 七、常見問題

**問：為什麼不能改 Email？**
答：Email 是「忘記密碼」寄重設信的地方，改錯會讓你再也收不到重設信，所以由系統管理員修改。

**問：角色或團隊不對，怎麼辦？**
答：請聯絡系統管理員在「使用者管理」調整。調整後你在下一次切換頁面時就會生效。

**問：管理員改了我的姓名，右上角怎麼還是舊的？**
答：切換一次頁面就會更新。

**問：登入紀錄裡有「登入失敗」，但不是我做的？**
答：有人用你的帳號試過密碼。請立即變更密碼，並把發生時間告訴系統管理員。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
