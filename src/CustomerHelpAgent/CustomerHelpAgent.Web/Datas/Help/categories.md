# 分類清單

維護「分類」這份清單：**新增、修改、停用、刪除分類**，並指定**哪些團隊可以使用**它。這裡建好的分類，會出現在「專案項目」的「分類」欄位與「分類過濾」下拉選單裡。

> 分類的「適用團隊」**留空代表所有團隊都能使用**，和專案的「團隊」留空（代表公開給所有人看）意思不同，設定前請先看第二段的說明。

### 一分鐘看懂這一頁

- **解決什麼問題**：統一管理專案可以使用的分類名稱，避免每個人各自打字，造成同一件事有好幾種寫法、事後難以篩選。
- **誰會用到**：負責整理資料定義的同仁或系統管理員；一般同事只會在專案的「分類」下拉選用這裡建好的分類。
- **它在系統的哪個位置**：左側選單「資料定義 › 分類清單」；這裡是「專案項目」分類欄位與分類過濾器的選項來源。
- **開始前要準備**：想好分類名稱；想限定使用範圍時，先確認對應的團隊已經在「團隊清單」建好並啟用，才能在「適用團隊」選到它。
- **做完會得到**：一個可以在專案項目中選用的分類；有指定適用團隊時，只有那些團隊的成員會在下拉選單裡看到它。
- **它不做什麼**：不決定專案的可見範圍（那是專案上的「團隊」），也不會回頭修改已經掛了這個分類的既有專案。

## 一、功能摘要

在這裡可以做什麼：

- 新增、修改、刪除分類（依你的權限顯示按鈕）。
- 在清單上直接點「啟用」標籤停用不再使用的分類（會先確認），再點「停用」就重新啟用，保留日後重新啟用的彈性。
- 為分類指定一個或多個「適用團隊」，讓下拉選單只給相關團隊看到。
- 輸入關鍵字搜尋分類的名稱與描述。
- 點表格欄位標題排序，用下方頁碼換頁（每頁 8 筆）。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 資料定義負責人 | 建立與整理分類，決定哪些團隊可以使用哪些分類。 |
| 系統管理員 | 看得到全部分類，處理「同事找不到某個分類」之類的問題。 |
| 一般同事 | 通常不進這一頁，只在專案項目的「分類」下拉選用分類。 |

### 「適用團隊」留空是什麼意思

「適用團隊」的**留空語意和專案相反**，這是最容易搞錯的地方：

| 畫面 | 團隊欄位留空的意思 |
|---|---|
| 專案項目的「團隊」 | 這筆專案公開給所有人看 |
| 分類清單的「適用團隊」 | **所有團隊都能使用這個分類**（視同公用分類） |

### 誰看得到哪個分類

- 分類**沒有指定適用團隊** → 所有人都看得到、選得到。
- 分類**指定了適用團隊** → 只有屬於其中任一團隊的人，才會在專案的分類下拉選單、以及**這份分類清單本身**看到它。
- **管理員**，以及**自己沒有任何團隊的使用者**，看得到全部分類。

這個過濾是讓下拉選單更精簡的便利設計，真正決定你能做什麼的是角色權限。你所屬的團隊，是使用者管理裡直接替你綁定的團隊，加上你所有角色的預設團隊。

> 適用團隊是用**團隊名稱**記住的；團隊在「團隊清單」改名時，分類上的名稱會自動跟著改。你所屬的團隊包含它們所有下屬部門（部門樹）。

### 停用與刪除的差別

- **停用**：分類不再出現在專案的「分類」下拉與「分類過濾」中；已經掛了它的專案**不受影響**，分類名稱照常顯示。
- **刪除**：分類從這份清單消失，但**不會檢查**是否還有專案在使用，也不會把名稱從既有專案上移除。0.9.94 起刪除可以還原（工具列的「顯示已刪除」），真正移除要再按「永久刪除」。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 檢視 | 進入畫面、搜尋與排序、看資料。沒有檢視權限時會看到「你沒有權限存取此頁面」。 |
| 新增 | 看得到工具列的「新增」按鈕。 |
| 編輯 | 看得到每列的「修改」按鈕。 |
| 刪除 | 看得到每列的「刪除」按鈕、表格最左邊的勾選框與工具列的「刪除選取」，以及工具列的「顯示已刪除」（可還原或永久刪除已刪除的資料）。 |

> 權限設定在「角色管理」權限設定的「資料定義管理功能 › 分類清單」底下；管理員看得到全部。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 新增、停用分類，或限定分類給哪些團隊用 | 這一頁 |
| 把分類貼到專案上、用分類篩選專案 | 「專案項目」 |
| 建立或停用「適用團隊」下拉裡的團隊 | 「團隊清單」 |
| 決定某位同事屬於哪些團隊 | 「使用者管理」「角色管理」（系統管理員） |

### 右下角的處理進度提示

這個畫面沒有長時間處理的工作，不會出現持續顯示的處理進度視窗。一般提示幾秒後會自動消失；錯誤或警告提示（例如失敗原因）會一直留著，右下有「複製」按鈕，按 X 才關閉。

## 四、建議這樣操作，會得到什麼

### 新增一個全公司共用的分類

1. 按工具列的「新增」，輸入名稱與描述。
2. 「適用團隊」保持空白，啟用狀態維持「啟用」。
3. 按「儲存」，在「確認儲存」選「儲存」。
4. 在「確認團隊設定」看到公用分類的提醒，確認無誤後選「仍要儲存」。

**會得到什麼**：所有使用者在專案項目的分類下拉選單都看得到這個分類。

### 讓某個分類只給特定團隊使用

1. 在該列按「修改」。
2. 在「適用團隊」選擇需要的團隊；若你自己不在這些團隊中，儲存時會提醒你存檔後將看不到它。
3. 按「儲存」並確認。

**會得到什麼**：只有所選團隊的成員（以及管理員與沒有團隊的使用者）會在下拉選單看到這個分類，其他人的選單更精簡。

> 業務一組想要一個只給自己用的分類「行銷」。負責人按「新增」，名稱填「行銷」，適用團隊選「業務一組」後儲存。之後王小明在建立專案「官網改版」時，就能在分類下拉選到「行銷」，而其他團隊的同事不會看到這個選項。

### 淘汰一個不再使用的分類

1. 點該列的「啟用」標籤。
2. 在「停用分類」確認窗按「停用」（也可以按「修改」把啟用狀態切到「停用」後儲存）。

**會得到什麼**：新專案選不到這個分類，但已經使用它的舊專案資料不受影響；比起直接刪除，停用保留了日後重新啟用的彈性。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **分類** | 替專案歸類的標籤，一筆專案可以掛多個分類，方便篩選。 |
| **適用團隊** | 可以在下拉選單裡選用這個分類的團隊；留空代表所有團隊都能用。 |
| **公用分類** | 適用團隊留空的分類，所有使用者都看得到、選得到。 |
| **啟用狀態** | 停用的分類不會出現在專案的下拉選單，但不影響既有專案。 |
| **你所屬的團隊** | 使用者管理裡直接替你綁定的團隊，加上你所有角色帶來的預設團隊。 |
| **（已限定其他團隊）** | 在專案的編輯視窗中，專案上掛著、但你目前的下拉選單選不到的分類（例如已停用或只限其他團隊）會加上這個標示；保留不動即可，存檔時不會被清掉。 |

## 七、常見問題

**問：為什麼同事看得到的分類，我在這份清單上看不到？**
答：那個分類只限其他團隊使用，而你不屬於其中任何一個團隊。這份清單和下拉選單套用同一套規則。需要使用時，請系統管理員調整你的團隊，或請負責人調整該分類的適用團隊。

**問：新增時說「分類名稱已存在」，可是清單裡明明沒有？**
答：名稱在全系統不可重複，包含你看不到的、只限其他團隊使用的分類。請換一個名稱，或洽系統管理員確認是哪一筆。

**問：分類的適用團隊留空，和專案的團隊留空一樣嗎？**
答：不一樣。分類留空代表所有團隊都能使用這個分類；專案留空代表這筆專案公開給所有人看。兩者都是「最寬鬆」，但一個管的是下拉選單，一個管的是資料可見範圍。

**問：我把分類停用了，為什麼舊專案上還看得到它？**
答：停用只會讓它從下拉選單消失，不會修改既有專案。在舊專案的編輯視窗中，它會以「（已限定其他團隊）」的標示保留在分類欄位裡，存檔時不會被清掉；若想移除，請在該專案中手動取消選取。

**問：看不到「新增」「修改」或「刪除」按鈕？**
答：你的角色缺少「分類清單」的對應權限（新增、編輯或刪除），請洽系統管理員調整角色。

**問：按「儲存」存檔時出現「這筆資料在你編輯期間已被其他人修改或刪除」？**
答：你開啟編輯視窗之後，有其他人先存檔（或刪除）了同一筆資料，系統為了不讓你的存檔蓋掉對方的修改而擋了下來（0.9.93 起）。視窗會維持開啟，你填寫的內容還在：請先把要改的內容記下來，按「取消」關閉視窗、重新開啟同一筆，確認對方改了什麼之後再編輯一次。

**問：刪錯了分類，可以救回來嗎？**
答：可以（0.9.94 起）。刪除只是把資料移到「已刪除」：按工具列的「顯示已刪除」，找到那一筆按「還原」即可，內容與刪除前相同。在「已刪除」清單裡按「永久刪除」之後就救不回來；沒有手動永久刪除的，刪除超過保留天數（預設 90 天，依系統設定）後，系統會自動永久刪除（0.9.97 起），請在那之前還原。看不到「顯示已刪除」按鈕表示你沒有刪除權限，請洽系統管理員。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
