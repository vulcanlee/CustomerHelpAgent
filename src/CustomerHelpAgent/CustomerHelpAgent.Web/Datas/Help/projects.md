# 專案項目

記錄團隊正在進行的**工作項目**，例如「官網改版」「年度客戶滿意度調查」，並記下**負責人、時程、狀態、優先級、完成百分比與相關附件**。瀏覽器分頁標題顯示「專案管理」，是同一個畫面。

> 你**只看得到**沒有指定團隊的公開專案，以及你所屬團隊（含它們所有下屬部門）的專案；管理員看得到全部。

### 一分鐘看懂這一頁

- **解決什麼問題**：一項工作牽涉多人、多份文件，進度容易散在信件與口頭；這一頁把每項工作的負責人、時程、進度與附件集中在一處。
- **誰會用到**：專案負責人／承辦同仁負責建立與更新；主管用來查看狀態、優先級與完成百分比。能不能新增、修改、刪除，依你角色的權限而定。
- **它在系統的哪個位置**：左側選單「專案管理 › 專案項目」；分類與團隊的選項來自「資料定義」底下的「分類清單」「團隊清單」。
- **開始前要準備**：專案標題與負責人姓名；想分類或限定可見範圍時，分類與團隊要先在「分類清單」「團隊清單」建好並啟用。
- **做完會得到**：一筆可搜尋、可依分類與團隊篩選的專案紀錄，附件集中保存（有編輯權限就能隨時下載），進度一目了然。
- **它不做什麼**：不會自動更新進度或通知負責人（狀態與完成百分比要手動修改），負責人也不會連到系統帳號；分類與團隊本身要到各自的清單頁維護。

## 一、功能摘要

在這裡可以做什麼：

- 新增、修改、刪除專案項目。
- 用「分類過濾」「團隊過濾」篩選，或輸入關鍵字搜尋。
- 為專案上傳附件（可一次選多個檔案），並下載已上傳的附件。
- 用「團隊」決定誰看得到這筆專案。
- 點表格欄位標題排序，用下方頁碼換頁（每頁 8 筆）。

這個畫面沒有需要長時間處理的工作，不會出現持續顯示的處理進度視窗。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 專案負責人／承辦同仁 | 建立與更新工作項目，記錄負責人、時程與進度，上傳需求文件、會議紀錄等附件。 |
| 主管 | 查看各項工作的狀態、優先級與完成百分比，掌握整體進度。 |
| 系統管理員 | 看得到全部專案，協助處理「同事看不到某筆專案」這類問題。 |

### 誰看得到哪筆專案

- 專案**沒有指定團隊** → 公開，所有能進這一頁的人都看得到。
- 專案**指定了團隊** → 屬於其中任一團隊的人看得到，這些團隊所有**上層部門**的成員也看得到（部門樹，見「團隊清單」）。
- 管理員看得到全部。

「你所屬的團隊」是兩部分合起來：管理員在「使用者管理」直接替你綁定的團隊，加上你所有角色在「角色管理」設定的預設團隊；你也看得到這些團隊所有下屬部門的專案。

新增專案時，系統會預先帶入你所屬、而且仍啟用中的團隊（不含下屬部門）；如果把團隊清空，儲存時會再提醒你「將對所有使用者公開可見」。

「團隊」只能選你看得到的團隊（你所屬的與它們的下屬部門）；這筆專案原本就有的其他團隊會保留在選項裡，可以留著或拿掉。原本有指定團隊的專案**不能改成公開**。管理員不受這些限制。

團隊是用**團隊名稱**比對的：團隊改名時，專案上的名稱會自動跟著改；團隊被停用後，原本屬於它的人仍然看得到它的專案。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 檢視 | 進入畫面、搜尋與篩選、看清單上的資料。 |
| 新增 | 看得到工具列的「新增」按鈕，可以建立專案。 |
| 編輯 | 看得到每列的「修改」按鈕，也才能打開視窗查看與下載已上傳的附件。 |
| 刪除 | 看得到每列的「刪除」按鈕、表格最左邊的勾選框與工具列的「刪除選取」，以及工具列的「顯示已刪除」（可還原或永久刪除已刪除的資料）。 |

> 權限設定在角色管理的「專案管理功能 › 專案項目」底下（「專案管理功能」就是選單上的「專案管理」群組）。能不能修改是權限決定的，和團隊是兩回事：看得到一筆專案，不代表可以修改它。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 記錄工作的負責人、時程、進度與附件 | 這一頁 |
| 新增或停用「分類」下拉裡的選項 | 「分類清單」 |
| 建立或停用團隊 | 「團隊清單」 |
| 決定某個人屬於哪些團隊 | 「使用者管理」（直接綁定）或「角色管理」（角色的預設團隊），限管理員 |
| 開放或收回「新增」「修改」「刪除」按鈕 | 「角色管理」，限管理員 |

### 新增／修改專案視窗

視窗分成「基本資料」「排程與進度」「分類與團隊」「專案附件」四區。

| 欄位 | 意思 | 範例 | 怎麼填或怎麼用 |

| 負責人 | 負責這項工作的人。 | 「王小明」 | **必填**。是純文字姓名，不會和系統帳號連動，打錯字也不會有人提醒。 |

| 狀態 | 工作目前的狀態。 | 進行中 | **必填**，五選一：未開始、進行中、已完成、暫緩、等待。新增時預設「未開始」。 |

| 已刪除 S 筆，F 筆未刪除：… | 「刪除選取」時有幾筆刪不掉，每筆後面寫著原因（例如已被別人刪除、不在你的團隊範圍內）；其他筆已經刪除。 |

### 右下角的處理進度提示

這個畫面沒有 AI 處理或產生 PDF 這類需要長時間處理的工作，所以不會出現持續顯示的處理進度視窗。一般提示幾秒後會自動消失；錯誤或警告提示（例如失敗原因）會一直留著，右下有「複製」按鈕，按 X 才關閉。

## 四、建議這樣操作，會得到什麼

### 建立一筆新專案

1. 按工具列的「新增」，開啟「新增專案」視窗。
2. 填寫「標題」「負責人」（必填），視需要填描述、開始日期與結束日期。
3. 選擇「狀態」「優先級」，輸入「完成百分比」。
4. 選擇「分類」與「團隊」；要讓所有人都看得到，就把團隊清空。
5. 需要時在「新增附件」選擇檔案，確認它們出現在「待上傳檔案」。
6. 按「儲存」，在「確認儲存」視窗再按一次「儲存」。

**會得到什麼**：一筆有負責人、時程與附件的專案紀錄，只有你指定的團隊（或所有人）看得到。

### 每週更新進度

1. 用關鍵字或「團隊過濾」找到要更新的專案。
2. 在表格該列按「修改」，更新「狀態」與「完成百分比」。
3. 需要時在「已上傳檔案」對舊版檔案按「移除」，再到「新增附件」選新版檔案。
4. 按「儲存」並確認。

**會得到什麼**：主管打開清單就能看到最新進度，附件也永遠是最新版本。

> 王小明建立一筆專案「官網改版」，負責人填「王小明」，狀態選「進行中」、優先級選「高」、分類選「行銷」、團隊選「業務一組」，並上傳主管核准的 `需求說明.pdf`。之後每週五更新完成百分比，主管打開「專案項目」、在「團隊過濾」選「業務一組」，就能掌握進度。

### 主管檢視整體進度

1. 在「團隊過濾」或「分類過濾」選要看的範圍。
2. 點「優先級」或「完成百分比」欄位標題排序。
3. 需要看附件時，按該列的「修改」打開專案，點已上傳附件的檔名下載需求文件或會議紀錄；沒有改任何欄位就直接按「取消」，不會跳確認窗。

**會得到什麼**：一眼看出哪些高優先的工作還落後。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **專案項目** | 一項要追蹤的工作，例如一次網站改版或一場活動。 |
| **負責人** | 負責這項工作的人，是自行輸入的姓名，不會連到系統帳號。 |
| **分類** | 貼在專案上的標籤，方便篩選；選項由「分類清單」維護。 |
| **團隊** | 決定誰看得到這筆專案；以團隊名稱比對，沒有指定團隊就是公開。上層部門的成員看得到下屬部門的專案。 |
| **公開** | 專案沒有指定任何團隊，所有能進這一頁的人都看得到。 |
| **你所屬的團隊** | 使用者管理替你直接綁定的團隊，加上你所有角色的預設團隊。 |
| **（已限定其他團隊）** | 專案上掛著目前選單裡沒有的分類；保留不動即可，存檔時不會被清掉。 |
| **待上傳檔案** | 已選好但還沒儲存的附件，按「取消」會一起丟掉。 |
| **附件** | 跟專案一起保存的檔案，例如需求文件、會議紀錄；刪除專案時保留（還原後可再下載），永久刪除專案時才一起刪除。 |

## 七、常見問題

**問：同事說看不到我建立的專案？**
答：專案的「團隊」決定誰看得到。指定了團隊時，只有該團隊的成員（以及管理員）看得到。要讓所有人都看得到，請修改專案、把團隊清空；或請管理員把同事加入該團隊。

**問：我明明存了一筆專案，存完卻在清單上找不到？**
答：最常見的原因是你把團隊改成自己不屬於的團隊，存檔後你就看不到它了，系統不會事先提醒。另外也請確認「分類過濾」「團隊過濾」與搜尋框是否還留著條件。需要找回時，請屬於該團隊的同事或管理員協助。

**問：團隊欄位留空，是不是就沒有人看得到？**
答：正好相反。團隊留空的專案是公開的，所有能進這一頁的人都看得到。要限制可見範圍，請至少指定一個團隊。

**問：儲存時出現「結束日期不可早於開始日期。」？**
答：請把結束日期改成開始日期當天或之後，或先清空其中一個日期再儲存。

**問：附件上傳失敗，顯示「檔案 … 的類型不在允許清單中。」？**
答：系統只接受常見格式，例如 PDF、Word、Excel、PowerPoint、圖片、文字檔、CSV 與壓縮檔；網頁檔、執行檔等不接受。請在「待上傳檔案」把它移除，轉成可接受的格式後再上傳。

**問：選了檔案，卻沒有出現在「待上傳檔案」裡？**
答：單一檔案超過 1GB 時，選檔當下就會被略過，右下角會出現「… 超過 1GB 限制」。請壓縮或拆成多個檔案後再選。

**問：在「分類」下拉找不到某個分類？**
答：可能是該分類被停用，或它只開放給其他團隊使用。請洽維護分類清單的同事或系統管理員。

**問：只加了附件、沒改欄位，按儲存會被當成沒有變更嗎？**
答：不會。新增或移除附件都算變更，會正常跳出確認視窗並儲存。

**問：負責人打錯字或那個人離職了，系統會提醒嗎？**
答：不會。負責人只是一段文字，不會和系統帳號比對，請自行修改。

**問：看不到「新增」「修改」或「刪除」按鈕？**
答：你的角色缺少「專案項目」的對應權限（新增、編輯或刪除），請洽系統管理員調整角色。

**問：只有檢視權限，要怎麼下載附件？**
答：附件只列在「修改專案」視窗裡，沒有「編輯」權限就看不到「修改」按鈕，也就無法下載。請洽系統管理員替你的角色加上「編輯」，或請有權限的同事代為下載。

**問：按「儲存」存檔時出現「這筆資料在你編輯期間已被其他人修改或刪除」？**
答：你開啟編輯視窗之後，有其他人先存檔（或刪除）了同一筆資料，系統為了不讓你的存檔蓋掉對方的修改而擋了下來（0.9.93 起）。視窗會維持開啟，你填寫的內容還在：請先把要改的內容記下來，按「取消」關閉視窗、重新開啟同一筆，確認對方改了什麼之後再編輯一次。

**問：刪錯了專案，可以救回來嗎？**
答：可以（0.9.94 起）。刪除只是把資料移到「已刪除」：按工具列的「顯示已刪除」，找到那一筆按「還原」即可，內容與刪除前相同，附件也還在。在「已刪除」清單裡按「永久刪除」之後就救不回來；沒有手動永久刪除的，刪除超過保留天數（預設 90 天，依系統設定）後，系統會自動永久刪除（0.9.97 起），請在那之前還原。看不到「顯示已刪除」按鈕表示你沒有刪除權限，請洽系統管理員。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖；右下角的錯誤訊息可按「複製」，內容、時間與錯誤追蹤碼會一起放進剪貼簿），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
